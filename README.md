概述:
Chinese Can Fly（CCF）是一个轻量的仅客户端的 Minecraft Forge 模组，需要 1.20.1 Forge 47.4.10+。
当玩家使用中文语言时，只需双击跳跃键（空格），即可在生存或冒险模式下像创造模式一样自由飞行。
无需开启作弊、无需管理员权限、服务端安装无效。
仅支持单人游戏：由于模组运行在客户端，无法在多人游戏中修改服务端的玩家能力。多人服务器中本模组不会生效。
灵感来源：中国人能飞（Fabric）。

功能特点:
双击空格切换飞行 —— 与创造模式的操作方式一致；
中文语言自动识别 —— 支持简体中文（zh_cn）、繁體中文（zh_tw）、繁體中文（香港特別行政區，zh_hk）、文言（華夏，lzh）；
仅生存/冒险模式生效 —— 创造与旁观模式由原版接管，不产生冲突；
落地自动退出飞行 —— 按住触地即退出飞行状态，再次双击空格即可重新起飞；
状态持久化 —— 飞行状态跨维度保留，重启存档、重启游戏保留；
创造 → 生存自动继承 —— 在创造模式飞行中切换到生存模式后仍保持飞行；
仅客户端运行 —— 服务端安装无效，单人无作弊也可使用；
命令添加 —— 使用指令（无作弊可使用）以切换该模组是否启用。
滞空修复 —— 1.3.0后，在飞行状态下，玩家的滞空挖掘惩罚不再生效。

BUG修复:
在CCF 1.3.0中，修复了“若飞行中的玩家按住Shift下降，但落地前松开Shift，由于惯性落地，则会导致无法再飞行”的BUG。
