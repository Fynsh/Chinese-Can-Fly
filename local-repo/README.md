# Local NeoForm BOM

This directory is a minimal local Maven repository containing:

```text
net.neoforged:minecraft-dependencies:1.21.1
```

The artifact is normally published to `https://maven.neoforged.net/mojang-meta/`,
which is unreachable from some networks. Gradle needs the generated module metadata
to build the NeoForge 1.21.1 compile classpath.

## Files

- `minecraft-dependencies-1.21.1.module` — generated by
  [neoforged/GradleMinecraftDependencies](https://github.com/neoforged/GradleMinecraftDependencies)
  with `-PminecraftVersion=1.21.1`.
- `minecraft-dependencies-1.21.1.pom` — minimal marker POM so Gradle discovers the
  adjacent `.module` file.

## When to regenerate

Regenerate this BOM if the Minecraft version changes. Run the generator for the new
version and replace both files here; keep the same directory layout.
